# Пресет управления Beebeeblock 3.07.8

Исходный выпуск `254cecf112683c4241da76d9e447e6fbdc422164` использует
Minecraft 1.21.1, NeoForge 21.1.251 и Java 21. Имена взяты из записанного
игрой `options.txt` экземпляра этой ревизии. Снимок этого файла имел
SHA-256 `8a5eb8cbf8e943705bab168616ee53fa5ecfcece3a3bfa76e6580c8d92477042`.
В репозитории хранится только таблица назначений, без личных настроек.

- J открывает квестбук, M — карту Xaero, F9 — карту FTB Chunks, F10 ставит
  метку FTB Chunks. R и U показывают рецепты и применения в JEI.
- B открывает рюкзак, G — Curios, N — беспроводной терминал AE2, O —
  переносной терминал Integrated Terminals. Гравис включает FTB Ultimine.
- В квестбуке Tab и Shift+Tab листают главы, а Ctrl+F6 открывает поиск.
  F12 и Shift+F12 листают вкладки терминала. При необходимости назначения
  можно поменять в игре. У 364 действий, включая большинство редакторских
  и редко используемых команд, клавиши по умолчанию сняты.

Контексты взяты из байткода установленных JAR и класса `Options` NeoForge.
Для FTB Quests отдельно проверен вызов `makeKeyMapping` с `ANY_GUI`.
Недостаточно изученные и нестандартные контексты считаются пересекающимися
со всеми остальными. Проверка учитывает основную клавишу и физический
модификатор. Она не исполняет обработчики модов, внутренние сочетания без
записи в `options.txt` и состояния интерфейсов. По заданию Minecraft
для проверки пресета не запускается.

```sh
python -B tools/keybinds/build_preset.py
python -B tools/keybinds/check_preset.py
```

После смены состава модов повторно сверяйте реестр из фактического
`options.txt` и пересматривайте раскладку для новых назначений.
